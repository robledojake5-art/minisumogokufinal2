# Proyecto "robot mini sumo Goku"

## Descripcion
Este proyecto del robot minisumo esta pensado para que luche contra otros minisumos en un area circular y mas especificame
los tire fuera del area de combate

##autores 

.Tomas Santino Robledo 

.Agustina Osorio 

fecha: abril 2026

## especificaciones generales 

.tipo: Robot Sumo Autonomo

.modo de funcionamiento: Autonomo

.Controlador: ESP32

.Alimentacion: Bateria

Estructura: Chasis diseñado para impresion 3D

##objetivo del proyecto 

el objetivo es desarrollar un robot mini sumo capaz de competir de manera autonoma contra otro robot

el sistema debe ser capaz de:

.detectar la presencia del oponente

.detectar los limites del area de combate

.avanzar, retroceder y girar

.Tomar desiciones automaticamente segun la informacion de los sensores

.empujar al oponente fuera del area de combate 

.mantenerse dentro del dehyo durante la competencia
